# 黃金 Range Filter 即時儀表板

單一 HTML 檔的黃金交易訊號分析工具，把 TradingView 上的 Range Filter 策略（Pine Script v5）
完整移植到前端，並修掉原始碼裡的三個問題。免安裝、免金鑰，開啟即用。

## 功能

- **雙策略並列**：上下兩套 Range Filter 同時跑（預設上 11 分、下 2 分），
  各有自己的訊號盒、K 線圖、取樣週期與範圍乘數，縮放也互不干擾
- **即時報價**：黃金代幣價格 + XAU/USD 現貨對照與溢價
- **訊號判讀**：每套策略各自顯示多空方向、最近訊號、持倉浮動損益
- **完整回測**：勝率、獲利因子、平均波幅、毛報酬 / 成本拖累 / 淨報酬、最大回撤、權益曲線
- **參數即時重算**：改參數不需重抓資料，且只重算被改的那一套
- **手機版面**：兩欄卡片，參數／訊號歷史／說明可收合

### 為什麼統計算 20000 根、畫面只顯示 2000 根

指標與回測要看得夠長才有統計意義，但 20000 根擠進一個畫面等於一片糊。
所以計算吃滿 20000 根，畫面預設只畫最近 2000 根，要看更早的用滾輪、
拖曳、雙指縮放或右上角的 ＋ － ⤢。「⤢」是回到 2000 根，不是攤開全部。

### 兩個週期只抓一次資料

11 分與 2 分都是由 1 分 K 線聚合出來的，而 2 分需要的 1 分資料是 11 分那份的子集合。
所以只抓一次最長的那份（約 33 萬根）兩邊共用——分開抓等於把最慢的那步做兩遍。

## 資料源

主源是 `https://api.binance.com/api/v3/klines`（PAXG/USDT 或 XAUT/USDT）。

PAXG 是 1:1 實體黃金背書的代幣，價格貼著 XAU/USD（溢價通常 < 0.3%）。
選它的原因是免金鑰、開放 CORS，而且**有真實成交量**——TradingView 的 `TVC:GOLD`
是現貨報價指數，多數 K 線沒有成交量，任何交易量過濾條件在上面都會恆為 false。

現貨對照價來自 `https://api.gold-api.com/price/XAU`。

### 備援鏈

單一資料源等於單點故障，Binance 打不通整頁就全黑。所以往下接三層：

| 順位 | 資料源 | K 線 | 現價 | 商品 |
|---|---|---|---|---|
| 1 | Binance | ✓ | ✓ | PAXGUSDT、XAUTUSDT |
| 2 | Coinbase | ✓ | ✓ | 只有 PAXG-USD |
| 3 | OKX | ✓ | ✓ | PAXG-USDT、XAUT-USDT |
| 4 | gold-api 現貨 | — | ✓ | XAU/USD（不是代幣本身） |

現價與 K 線分開走鏈：現價每秒打一次，換一家的成本很低，一失敗就立刻試下一家；
K 線換一家卻要重抓幾百個請求，所以只在主源真的抓不到時才切。

**備援不是等價替代。** 實測 2026-09-07 的 PAXG 1 分 K，每分鐘有成交的比例：

| 資料源 | 有成交的分鐘 | 與 Binance 收盤中位偏差 |
|---|---|---|
| Binance | 93.7% | — |
| OKX | 37% | 0.018% |
| Coinbase | 30% | 0.019% |

價格本身很接近（中位偏差 0.02%），但**成交的稀疏程度差很多**。備援那兩家沒成交的
分鐘會被補成「沿用前一根收盤、量記 0」的 K 棒，否則同樣一段時間的根數只剩三成，
Range Filter 的取樣週期意義會整個跑掉。補歸補，那些棒子不是真的行情，
所以訊號與淨報酬跟平常不會一樣 —— 切到備援時畫面下方會掛一條常駐提醒，
參數面板也會標出目前的 K 線來源。Binance 恢復後重新整理就會切回主源。

（OKX 那 37% 是它自己回傳零量 K 棒；Coinbase 是乾脆不回傳沒成交的分鐘，
所以它回來的資料看起來「零量佔 0%」，那是統計錯覺，實際填充率更低。）

## 三個關鍵修正

原始 Pine Script 有三個會讓分析結果失真的問題，本頁都已處理：

**1. ATR 過濾是無效程式碼**
原碼 `atr_lower = close - atr*mult` 後判斷 `close > atr_lower`。ATR 恆為正，
這個條件永遠成立，空方同理。該開關勾或不勾，訊號完全一樣。已移除。

**2. 暖機區假訊號**
`smoothrng` 內層 EMA 週期是 `per*2-1`，約需 3 倍長度才收斂。在此之前通道偏窄，
會噴出大量假訊號。實測 `per=390` 時，65 個訊號有 54 個擠在前 500 根。
本頁自動剔除前 `6*per` 根的訊號，不列入圖表與統計。

**3. 24/7 資料與真實黃金不符**
PAXG 全年無休，真實黃金週末休市。`smoothrng` 算的是 `|x - x[1]|` 的 EMA，
少了週末跳空會低估波動、通道偏窄、訊號暴增。同一組參數在五週內，
24/7 資料出 9 個訊號，剔除休市後只出 2 個——後者才與 TradingView 吻合。
「黃金交易時段」開關預設開啟（週日 22:00 UTC 開盤 → 週五 21:00 UTC 收盤，每日 21:00–22:00 休息）。

## 預設參數

以 20,000 根 11 分 K 線（223 天）掃描驗證的組合：

| 項目 | 值 |
|---|---|
| 週期 / 根數 | 11 分 / 20000 |
| 源 | (H+L)/2 |
| 取樣週期 | 300 |
| 範圍乘數 | 23 |
| 單趟成本 | 0.05% |

回測結果：16 筆交易、勝率 56.3%、獲利因子 4.43、平均持倉 12 天、
平均波幅 4.04%、淨報酬 +40.64%、最大回撤 5.98%。

篩選時要求三個時段皆不虧損、單筆獲利不超過淨利 80%、平均波幅遠大於交易成本，
以避開過度擬合與過度交易。

## 使用

直接開 `index.html` 即可。要在手機上看，用區網伺服器：

```bash
python -m http.server 8777 --bind 0.0.0.0
```

11 分與 2 分為交易所未原生提供的週期，由 1 分 K 線在前端聚合（時間桶對齊 Unix epoch）。
20,000 根 11 分需抓約 33 萬根 1 分線、發送約 330 個請求，載入需一段時間，
因此自動更新預設關閉。

## 授權與免責

僅供分析研究，不構成投資建議。黃金代幣與 XAU/USD 現貨存在溢價與價差，
適合判斷方向與型態，不宜當作報價來源。回測的最大回撤為「平倉權益」回撤，
未計持倉期間的浮動虧損，實際體感會更大。
