# research —— 黃金擇時策略的長期驗證

儀表板本身只跑 Binance 的 PAXG（2020 年之後）。**那段是純多頭，任何偏多的結構
都會被獎勵**，用它驗證擇時策略會得到過度樂觀的結論。這個資料夾用 Yahoo 的
GC=F（26 年，含 2011–2015 那波 −43.8% 的大空頭）做長期驗證。

## 檔案

| 檔案 | 用途 |
|---|---|
| `gold_data.py` | Yahoo 日線抓取與快取（GC=F / GLD），含 API 的坑 |
| `engine.py` | 回測引擎與策略訊號 |
| `compare_strategies.py` | 現成策略在 26 年上的比較＋依市況分段 |
| `robustness.py` | 回看期敏感度 × 雙資料源 × 前後半段分割 |
| `dual_confirm.py` | 雙確認防護（自行設計，**已證實失敗**） |
| `new_indicators.py` | 動量廣度、新高密度（自創指標，**未勝出**） |

```bash
cd research
python compare_strategies.py        # 或 python compare_strategies.py GLD
python robustness.py
python dual_confirm.py
python new_indicators.py
```

資料會快取到 `research/data/`（已 gitignore，可隨時重抓）。

兩個回測函式不要混用：`run()` 是交易配對法，只能處理全額進出；
`run_scaled()` 是逐日權益法，支援分數部位、成本按部位變化量計。
要互相比較時請讓所有策略走同一個函式。

## 綜合結論（2026-09-13）

測過七種結構完全不同的策略、三個資料源（GC=F 26 年、GLD 21.8 年、PAXG 6 年）：
Range Filter（15分/1h/4h/日線）、Faber 200MA、TSMOM（回看期 1–24 月全掃）、
Donchian（20/10、55/20、100/50）、雙確認防護、動量廣度、新高密度。

**四個一致的發現：**

1. **沒有任何策略能穩定贏過買進持有。** 風險調整後最好的 TSMOM12（33.49）
   仍略低於買進持有（33.64），換到 GLD 就輸掉。
2. **近十年全面失效。** 樣本對半切，後半段（GC=F 2013 起、GLD 2015 起）
   沒有任何策略、任何參數贏過買進持有。長期數字的優勢幾乎全來自前半段。
3. **做空系統性虧錢。** 四個週期的空單全為負：15 分 −1.09%、1 小時 −38.46%、
   4 小時 −34.32%、日線 −26.48%，而且加空單一定推高回撤。
   **「空手避險」有效，「做空獲利」無效** —— 這兩件事必須分開看。
4. **擇時唯一穩定成立的能力是降低回撤。** 跨資料源、跨參數、跨結構都成立，
   是唯一沒被推翻的東西。

**真正的選擇是一條取捨曲線，回撤要用報酬去買：**

| 配置 | 26 年報酬 | 最大回撤 | 2011-15 空頭 | 換手 |
|---|---|---|---|---|
| 買進持有 | +1492% | 44.4% | −42.4% | — |
| TSMOM12 只做多 | +1153% | 34.4% | −24.6% | 11.6 月 |
| 廣度 × 密度 | +299% | **17.0%** | **−14.4%** | 1.2 月 |

要不要用擇時、用哪一個，取決於對後市的判斷，回測答不了。
沒有大空頭時，擇時就是持續扣報酬。

**另一個保留**：儀表板現用的 15 分 Range Filter（六年 PAXG +127.2% / 回撤 13.08%）
無法在 26 年含空頭的樣本上驗證，因為 Binance 沒有 2020 年以前的資料。
它的可信度結構上低於這裡驗證過的策略——不是說它不好，是我們不知道它在大空頭裡會怎樣。

## 失敗的嘗試（不要重做）

**雙確認防護**（`dual_confirm.py`）：12 個月動量與 200 日均線「同時」轉空才出場，
預設持有。設計方向是對的——AND（30.70）遠勝 OR（19.20），換手從 40 降到 25——
但沒有解決後半段失效（5.16 vs 全抱 9.22），而且出場門檻變嚴的代價是保護力下降
（空頭 −29.5%，不如 TSMOM 的 −24.6%）。

**這暴露一個逃不掉的蹺蹺板**：出場門檻嚴 → 多頭段保得住但空頭保護弱；
門檻鬆 → 保護強但多頭段被巴。單純調整「何時出場」跳不出這個取捨。

**自創指標**（`new_indicators.py`）：動量廣度（1/3/6/12 月動量一致性）與
新高密度（年度高點貼近頻率），刻意不引入可調門檻。兩者單獨都輸，但相乘
（「廣度 × 密度」）把最大回撤壓到 **17.0%**——全期沒有其他策略做到過，
大空頭只虧 14.4%、換手 1.2 個月一次。代價是報酬只剩 +299%。
GLD 上風險調整大幅落後（8.58 vs 17.51），但**回撤控制有重現**（19.9% vs 45.6%）。

這兩個指標帶有選擇偏誤（「選中這兩個維度」本身就是一種挑選），
可信度天生低於有外部文獻支持的 TSMOM。

## 兩個會讓結論整個翻掉的坑

**1. Faber 200MA 與 TSMOM 必須月頻檢查。**
原始規格是「每月最後一個交易日看一次」。寫成每日檢查的後果：200MA 從 21 筆
變成 104 筆，而且在 2011–2015 空頭只擋下 −37.0%（全抱 −43.8%）等於沒保護 ——
均線附近反覆穿越被來回巴。**再平衡頻率跟參數一樣是策略規格的一部分。**
反過來 Donchian 本來就是日頻策略，不要改成月頻。

**2. 成交假設**：這根收盤產生訊號、**下一根開盤**成交。改成當根收盤成交會用到
當下還不知道的價格，回測會虛胖。

## Yahoo API 的坑

- 必須帶瀏覽器 User-Agent，否則一律 **429**（curl 預設 UA 連三次都被擋）。
- 全歷史要用 `period1=0&period2=<now>`；`range=max` 會被降成月線只給 268 根。
- `interval=15m` 配 `period1/period2` 會回 **422**，短週期要改用 `range=60d`。
- `^XAU` 是費城金銀「礦業股」指數，不是金價，不要拿來當黃金樣本。
